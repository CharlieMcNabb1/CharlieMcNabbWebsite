WinFastCleaner

Rust · Windows 10/11 · open source

A fast, safe disk cleaner for Windows and an open-source alternative to CCleaner. It shows exactly what it will delete before it deletes anything.

  • Reads the NTFS Master File Table directly, so a full drive scan takes seconds
  • Every cleanable item is color-coded by risk, and nothing personal is selected automatically
  • Deleted files go to a recovery bin you can restore from
  • No ads, no accounts, no telemetry, and it works fully offline

ScreenLink

Rust · Tauri · TypeScript · private source

Streams a gaming PC's screen to a laptop on the same home network at 1080p and up to 240 Hz. One app installs on both machines and drives Sunshine and Moonlight for you.

  • Pair with a 4-digit PIN that expires after 5 minutes and locks out after 3 wrong tries
  • Pick 60, 120, 144 or 240 Hz per session, or set a custom default
  • Only connects to local network addresses and never opens firewall ports
  • Logins live in Windows Credential Manager, never in a file

Fusion Reactor Controller

Lua · ComputerCraft · Minecraft

An automation script for the Better Fusion Reactors mod. It tunes control rods and fuel injection to keep the reactor near 100% efficiency without overheating.

  • Adaptive control steps make large corrections fast and fine-tune near the target
  • A cooldown after each direction change stops the rods from oscillating
  • Searches for the injection rate that keeps the heat multiplier lowest
