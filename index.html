WinFastCleaner

Rust · Windows 10/11 · open source

A fast, safe disk cleaner for Windows and an open-source alternative to CCleaner. It shows exactly what it will delete before it deletes anything.

  • Reads the drive's own file index (the NTFS Master File Table) directly, so a full scan takes seconds
  • Every cleanable item is color-coded by risk, and nothing personal is selected automatically
  • Deleted files go to a recovery bin you can restore from
  • No ads, no accounts, no telemetry, and it works fully offline

ScreenLink

Rust · Tauri · TypeScript

Streams a gaming PC's screen to a laptop on the same home network at 1080p and up to 240 Hz. One app installs on both machines and sets up Sunshine and Moonlight, the open-source streaming tools, for you.

  • Pair with a 4-digit PIN that expires after 5 minutes and locks out after 3 wrong tries
  • Pick 60, 120, 144 or 240 Hz per session, or set a custom default
  • Only connects to local network addresses and never opens firewall ports
  • Logins live in Windows Credential Manager, never in a file

Fusion Reactor Controller

Lua · Minecraft (ComputerCraft)

A feedback controller for the Better Fusion Reactors Minecraft mod. Every cycle it reads the reactor's efficiency and error level, then adjusts the control rods and fuel injection to hold it near 100% efficiency without overheating.

  • Adaptive step size: big corrections when far from the target, fine steps close to it
  • A cooldown after each direction reversal keeps the rods from oscillating
  • Searches for the injection rate that keeps the heat multiplier, and so the reactor's heat, lowest
